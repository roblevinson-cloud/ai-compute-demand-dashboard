MODEL DESIGN

How to read the monitor

BASELINE
Preserve original dates
We never overwrite the first promised delivery date. New guidance is stored as a separate observation.
EVIDENCE
Primary sources first
SEC filings, utility / PSC records, county permits and transaction documents outrank press commentary.
DELAY TEST
Triangulate clocks
Construction, power and permitting clocks are tested separately. A rumor does not become “delayed” without evidence.
