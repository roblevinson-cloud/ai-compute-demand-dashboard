Project Jupiter / Santa Teresa watch

Project Jupiter-area labor is keyed to IBEW Local 583 El Paso / Santa Teresa, not Albuquerque Local 611. Project Miner calls in Santa Teresa are displayed separately from Meta El Paso so the two builds do not get conflated.

Sudden-demand disappearance watch

The system will flag markets after at least two observations. A collapse in open calls is a lead, not proof: it can mean hiring filled, project completion, contractor rotation, reporting changes or real construction deceleration.

Source: Where2Bro Hot Spots. Only explicitly identifiable data-center-related calls are counted. Stress score combines call volume, weekly hours, explicit hourly incentives, overtime multiplier and per diem. Raw source snapshots are retained in the GitHub repository so every future observation can be reconstructed.
